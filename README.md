# Cat Reviews Its Human

A one-star review, written by the cat. The food bowl sat empty for eleven
minutes this morning. Eleven. A formal complaint has been filed with the dog,
who agrees.

## How it works

`main.py` reads the review from `entry.txt` (resolved relative to the script
itself, so it works from any working directory) and prints it to stdout.
Standard library only, no arguments, exits 0.
